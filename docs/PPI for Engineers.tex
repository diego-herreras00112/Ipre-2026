Handover count (case granularity) & \dtime & \gcase & \(\indh(c)\) & \(\sum_{i \in \fninst(c)} \fndres(i)\)
\newline
Here, \(\fninst(c)\) is the set of activity instances in case \(c\), \newline \(\fndres(i)\) returns the number of distinct resources involved in the execution of activity instance \(i\). 
\newline The formula sums these values to obtain the total handovers in case \(c\). \\
\hline

\newline $g$ represents the group of cases under analysis.
\newline $\indh(c)$ returns the handover count of case $c$.
\newline $\indc(g)$ returns the case count of group of cases $g$.\\

Idle Time (case granularity) & \dtime & \gcase & \(\indit(c)\) &
\(\sum_{i \in \fninst(c)} 
\begin{cases}
\frac{\indwt(i)}{|\fnconcstr(i)|} & \text{if } \fnprevstr(i) = \emptyset \\
0 & \text{if } \fnprevstr(i) \neq \emptyset
\end{cases}\)
\newline $\fninst(c)$ returns the set of activity instances that occur in case $c$.
\newline $\indwt(i)$ returns the waiting time of activity instance $i$.
\newline $\fnconcstr(i)$ returns the set of concurrent structures (parallel branches) related to instance $i$.
\newline $\fnprevstr(i)$ returns the preceding structure of activity instance $i$.\\
\hline

Expected Idle Time (group of cases granularity) & \dtime & \ggroup & \(\utexpected\indit(g)\) &

\newline $g$ represents the group of cases under analysis.
\newline $\indit(c)$ returns the idle time of case $c$.
\newline $\indc(g)$ returns the case count of group of cases $g$.\\

Lead Time (activity instance granularity) & \dtime & \ginst & \(\indlt(i)\) &

\newline $\indst(i)$ returns the service time of activity instance $i$, representing the time between its start and completion.
\newline $\indwt(i)$ returns the waiting time of activity instance $i$, representing the idle period before the instance starts execution.\\

Lead Time (activity granularity) & \dtime & \gact & \(\indlt(a)\) &
